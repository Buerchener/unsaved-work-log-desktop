# 未保存的工作日志 · 第一幕 v0.4

直接双击 `index.html`，或从本地预览服务器打开。无需安装依赖，无在线资源或真实账号。

首次进入是个人电脑桌面。桌面图标双击（触屏单击）打开；任务栏单击切换。约一秒后主管发来消息，点击通知进入工作。文件、私人聊天与个人软件可独立叠放，窗口右上角可最小化、最大化和关闭；右下角可拖动缩放。

开始菜单位于任务栏中央：电源按钮提供离开电脑；“帮助与存档”中可重新开始。桌面右键→个性化，可以切换背景。保存工作日志不会下班；离开电脑时确认赴约或休息；晚间有结果后合上电脑，到周二入口结束。

主要文件：
- `app.js`：原有故事、任务、回复、实际行动、日志与存档兼容。
- `desktop.js`：窗口管理、桌面、任务栏、跨应用通知与未读。
- `leisure.js`：文件、翻牌、音频、相册、便笺。
- `desktop.css`：Windows 11 风格桌面和个人应用视觉。
- `windows-shell.js`：开始菜单、Fluent 图标、右键菜单、快速设置与壁纸个性化。
- `office.css`：限定范围的办公文档、聊天及确认层样式。
- `assets/`：内置 imagegen 生成的相册 PNG、网络下载的微软官方壁纸、原创合成 WAV。来源与完整提示词见 `assets/ASSET_SOURCES.md`。
- `DESIGN.md`：当前设计规范。
- `v0.4_验收与变更.md`：实际测试与环境限制。
- `screenshots/v04/`：实际浏览器运行截图。

存档保存在当前浏览器、当前打开地址下。直接打开文件与本地服务器使用不同的存储来源，进度不自动互通。v0.4 与 v0.3 / v1 的存档键独立，旧键不会因升级删除；迁移说明可在帮助中查看。音乐必须主动点击播放。

原始 ZIP 和旧版本回退包保留在项目上级目录。只覆盖工作目录内的相关工程，不改动其他作业资料。
